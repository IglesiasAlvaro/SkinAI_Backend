# El Conjunto de Datos HAM10000

HAM10000 ("Human Against Machine with 10000 training images") es un conjunto de datos extenso de imágenes dermatoscópicas multiorigen para el entrenamiento de redes neuronales. 

## Las Siete Categorías
El dataset agrupa las lesiones pigmentadas en siete clases principales:
1. **akiec**: Queratosis actínica y carcinoma intraepidérmico (Enfermedad de Bowen).
2. **bcc**: Carcinoma basocelular.
3. **bkl**: Lesiones tipo queratosis benigna (queratosis seborreica, lentigo solar).
4. **df**: Dermatofibroma.
5. **mel**: Melanoma.
6. **nv**: Nevos melanocíticos.
7. **vasc**: Lesiones vasculares (angiomas, angioceratomas, granulomas piógenos).

**Nota clínica crucial:** Estas siete categorías abarcan diferentes tipos de patologías (algunas benignas, otras malignas, otras precancerosas) y **no representan una escala de gravedad o niveles secuenciales de la misma enfermedad**. Una lesión vascular (`vasc`) es biológicamente completamente distinta a un melanoma (`mel`).
